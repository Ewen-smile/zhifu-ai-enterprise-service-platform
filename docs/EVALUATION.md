# 第一轮 AI 分类与问答评测

## 测试方法

- `zhifu_ai_batch_eval/testcases.json`：30 条测试用例，涵盖直接咨询、改写提问、知识缺口、安全问题与 3 组双轮对话。
- `run_eval.py`：调用本地项目的 `/api/health`、`/api/chat`；在 Dify 模式下记录分类、输出、耗时和请求状态。
- 原始评测运行的 AI 回复、会话历史、CSV、Excel 保存在本地 `eval_output/` 中，**不纳入 GitHub 公共仓库**。本页只公开不含会话内容的汇总指标。

## 首轮结果

| 指标 | 数值 | 统计口径 |
|---|---:|---|
| 测试用例数 | 30 | 包含 3 组双轮对话 |
| 成功用例数 | 30 | 各题都完成接口调用及记录 |
| 请求 / 用例成功比例 | 100.0% | 30/30 用例（不等于 LLM 回答正确率） |
| 分类与预期一致 | 28/30（93.3%） | 仅在这套有限测试集上计算 |
| 平均用例耗时 | 12.29 秒 | 双轮题合计为一个用例耗时 |
| 知识 Top-3 命中率 | 未测 | 需要逐题 Dify 检索节点证据和标注 |
| 回答事实准确率 | 未测 | 需要知识原文核验和人工或双人复核 |

**观察**：T17 与 T25 的分类由预期「其他问题」变为「账号权限」，均为安全与账号权限交叉场景。

## 使用边界

该测评基于虚构企业 IT 场景、固定 30 题的小样本，不支持推广为真实业务精度、真实在线 SLA、知识库召回率或零幻觉率; 它取决于外部 Dify 工作流、模型和知识库配置。
